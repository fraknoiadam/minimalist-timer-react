Quick Links Editor

Edit the Quick Links buttons on the timer's start screen. Saved changes show up the next time the timer page is loaded.

    Format

    Each preset is one button. Its settings override defaults; a setting set in neither is left as it is when the button is clicked.

    {
  "defaults": {
    "linkSwitchDurationSec": 15,
    "embedFadeOutMin": 10
  },
  "presets": [
    {
      "name": "Results",
      "links": ["https://example.com/results"]
    },
    {
      "name": "Final",
      "links": ["https://example.com/a", "https://example.com/b"],
      "linkSwitchDurationSec": 30,
      "darkMode": false,
      "fontSize": 12
    }
  ]
}
    FieldValue
    nameButton label. Required in every preset, not allowed in defaults.
    linksList of full https:// URLs, shown one after another.
    linkSwitchDurationSecSeconds before switching to the next link, at least 1.
    embedFadeOutMinThe links disappear when less than this many minutes are left.
    darkModetrue or false.
    fontSizeTimer size, at least 1.
    embedOverflowtrue or false.
    wakeLockEnabledtrue or false: keep the screen on.
